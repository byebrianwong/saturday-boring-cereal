(`var(--orange)`), not the hex values, so a colour change happens in one place.

## Type

There are no web fonts. All three families are system fonts, so they look
different on machines that lack them. Chromatic's snapshot browser has Impact
but not Arial Narrow, so in Chromatic snapshots the `--fine` text falls back to
regular-width Arial and runs wider than it does on a Mac.

## Shared classes

These classes in `global.css` are used across pages, so components and pages
reuse them instead of restyling.

<div style={{ display: 'flex', flexWrap: 'wrap', gap: 28, alignItems: 'center', padding: '20px 0' }}>
  <span className="section-kicker">.section-kicker</span>
  <span className="btn-turq">.btn-turq</span>
  <span className="btn-ink">.btn-ink</span>
  <span className="score-badge starburst">
    <span className="sv">8.5</span>
    <span className="so">.score-badge</span>
  </span>
</div>

- `.starburst` clips any box into the 24-point sticker shape.
- `.rays`, `.rays-fine` and `.rayband` are the sunburst backgrounds. They are
  the most expensive thing to draw on the page, so keep them few and only ever
  animate them with `transform`.
- `.fineprint` is the two-column small-print box the Disclaimer uses.

**A trap:** page CSS must not reuse the global component class names
(`.macros`, `.score`, `.box`, `.tags`, `.brand`). Astro scopes page styles,
so the page's rules win, but any property the page does not set still comes
through from `global.css`.
